01 / Getting started

Open the workspace

plottwist translates MATLAB scripts into Python, executes the Python, and displays scientific plots and command output. It is intended for numerical and DSP coursework within the current translation scope.

  1. Choose Workspace in the navigation.
  2. Start with the sampled sine wave already in the editor, or replace it with your MATLAB source.
  3. Press Run, then inspect Python, figures, and the command window.

No account is required. Keep cookies enabled for access to your session’s results and downloads. The optional Workspace tour button explains the controls and can be replayed at any time.

02 / Source

Enter MATLAB code

The MATLAB source panel is editable. Paste a complete numerical script with the variables and plotting commands it needs. Clear source empties the editor when JavaScript is available; you can also select and replace the text directly.

For a small first example, use the workspace’s sampled sine wave:

% A sampled sine wave
fs = 1000;
t = 0:1/fs:0.1;
f = 50;

x = sin(2*pi*f*t);

plot(t, x);
xlabel('Time (s)');
ylabel('Amplitude');
grid on;

MATLAB source is limited to 64 KiB of UTF-8 text. Start with a small, self-contained script; external files, interactive input, and additional dependencies do not fit this workflow.

03 / Run

Translate, then execute

The current workspace uses Groq-powered translation; there is no translation engine selector. Run sends your submitted MATLAB source to Groq. Read the Privacy Policy before submitting sensitive material.

  1. Press Run above the editor.
  2. Translation returns generated Python and any translation warnings.
  3. If translation succeeds, a separate Python process executes the generated code.
  4. Review the results and the status beside Run.

With JavaScript enabled, Run is disabled and the editor is temporarily read-only while the request is active. Wait for it to finish. Duplicate runs from the same established session are rejected.

The configured Python execution timeout on this server is {{ execution_timeout_seconds }} seconds, including library startup and figure rendering. Translation has its own timeout. A successful translation can still lead to an execution failure.

Without JavaScript, the native Run form still submits and renders the workspace response. Copy buttons, bulk selection controls, and the interactive tour require JavaScript.

04 / Translation

Understand the generated Python

The Generated Python panel is selectable, scrollable, and read-only. Change MATLAB and run again to request another translation. Use Copy or Download Python if you want to inspect or edit the Python in your own environment.

Review imports, array shapes, indexing, sample counts, matrix operations, and the numerical methods. Passing Python syntax validation does not prove that the translation preserves your MATLAB script’s meaning.

When execution fails after translation, the Python and translation warnings remain visible. The warning link below the code takes you to the command window.

05 / Figures

Read the plots

The Figures area displays captured Matplotlib figures in their creation order. A figure containing several subplots is one figure for selection and export. Check titles, axis labels, units, and scales against your exercise.

A successful run may produce no figures if the code performs calculations without plotting. Some runtime failures can retain figures created before the error; a timeout returns no captured figures.

06 / Feedback

Output, warnings, and errors

The Command window shows printed values, translation warnings, a short error if a stage fails, and execution duration when available. No standard output means the code printed nothing; it does not by itself mean the run failed.

FeedbackMeaning and next step
Translation warningsThe provider flagged an unsupported construct or ambiguity. Read each warning and compare the code with your intended mathematics.
Translation failedNo usable Python was returned. Execution did not start. Review the warnings and simplify the MATLAB, or retry if the provider is unavailable.
Execution failedTranslation produced Python, but source checks, runtime, or rendering failed. Inspect the retained Python and short error before changing MATLAB.
Execution diagnosticsExpand this disclosure when it appears to read additional diagnostics. Private diagnostic lines and raw runtime tracebacks may be omitted.

Each output stream is bounded to 64 KiB; long output may show [Output truncated]. Execution duration includes process startup and rendering, rather than measuring only your numerical computation.

07 / Selection

Choose the figures you need

Every figure is checked when new results arrive. Use the checkbox beside Figure 1, Figure 2, and so on to choose what goes into a combined document.

Select all and Clear selection update the checked figures and selected count when JavaScript is available. With none selected, combined exports are disabled. Individual figure downloads remain available.

A new run starts a fresh selection with all its figures checked. Combined exports always follow the original figure order, regardless of the order in which you select them.

08 / Exports

Download individual or combined figures

Individual figure: choose PNG, PDF, or DOCX beneath that figure. Its checkbox does not need to be selected for an individual download.

Combined document: check at least one figure, then choose Combined PDF or Combined DOCX in the Figures toolbar. PDF exports contain one figure per page; DOCX exports insert page breaks between figures, with final layout depending on the word processor.

Exports reuse the PNGs captured during the run. Downloading does not translate or execute your code again. PDF and DOCX contain plot images, rather than editable plotting data.

Stored results expire {{ artifact_ttl_seconds }} seconds after creation on this server. Use the same browser session and download what you need before expiration. If a result is unavailable, run the source again.

09 / Source files

Keep Python and original MATLAB

Download Python
In the Generated Python header. Downloads the generated source as generated.py.
Download MATLAB
In the MATLAB source header after a run has stored translated Python. Downloads the original source submitted for that displayed run as generated.m.

Source downloads are tied to the stored run. Unsubmitted editor changes do not change its MATLAB download. Both source downloads can remain available after an execution failure; a translation failure without Python creates no new downloadable result.

Copy MATLAB reads the current editor text, while Copy Python reads the displayed translation. If clipboard access fails, select the code and copy manually. Copies and downloads do not submit another run.

10 / Compatibility

MATLAB scope and known limitations

The Groq translator is instructed to handle the numerical and elementary DSP scope below. This is a defined translation scope, not an exhaustive function-by-function compatibility guarantee. Provider-generated Python must still pass source checks and execute with the available libraries.

ScopeWhat to review
Variables, numerical expressions, common mathematical functionsData types, complex values, units, and mathematical intent.
Vector and matrix construction, colon expressionsRow/column shapes, inclusive endpoints, step direction, and sample count.
Basic indexing, including endMATLAB’s 1-based indexing and column-major linear indexing versus Python indexing.
Matrix and element-wise operations* versus .*, division and solves, powers, and conjugate versus nonconjugate transpose.
Signal generation and elementary DSPSampling rate, normalization, FFT dimensions, boundary behavior, and numerical method.
Basic plots, figures, subplots, labels, legends, grid, and holdFigure separation, subplot organization, scales, and clear axis labels.

Specialized toolboxes, arbitrary MATLAB programs, and syntax beyond this scope may fail or need another translation approach outside this workspace. Unsupported essential operations can produce no Python; ambiguous constructs may produce warnings.

File and network access, interactive input, arbitrary imports, and code that exports its own files are outside the execution workflow. Use the workspace’s export controls. Python execution permits the installed scientific libraries and selected standard-library modules, with checks on imports and operations.

A run is limited to 20 figures, 5 MiB per PNG, 20 MiB of PNGs in total, and 4 million pixels per rendered figure. Large arrays or long calculations may also exceed the runtime limit. These controls do not provide a complete sandbox or universal MATLAB compatibility.

11 / Troubleshooting

Common problems

Translation is unavailable, rate-limited, or times out

For a temporary provider error, wait and retry with a shorter script. Missing credentials or provider authentication errors need the server operator to check configuration. Changing MATLAB cannot repair a server credential problem.

Unsupported syntax or unexpected Python

Read translation warnings. Reduce the example to the operation that fails, and express it using the numerical scope above. Compare matrix operations, indexing, and sample counts. Download Python to inspect it locally; the workspace panel is read-only.

Execution failed or exceeded the timeout

Inspect the generated Python and error in the command window. Reduce array sizes, figure count, or computation. An import or operation rejected by execution checks must be removed from the workflow. Translation success does not override execution limits.

The run completed without plots

Check that your MATLAB actually creates a plot or figure. Printing a value or calculating an array does not create a Matplotlib figure. If your exercise only needs numbers, review the command output.

Combined export is disabled

Check at least one figure. The figure checkboxes determine the combined document. Individual PNG, PDF, and DOCX links work independently of this selection.

A figure or download is unavailable

Use the same browser session that ran the code and keep cookies enabled. Results expire after {{ artifact_ttl_seconds }} seconds on this server. Run the source again if the result has expired or the session was cleared. Temporary storage failures also prevent downloads.

The request was rejected or the connection failed

Refresh the workspace to renew the form’s request protection, then retry. Keep a copy of unsubmitted source before refreshing. If a run is still active in your session, wait for it to finish before starting another.

Copy does not work

Your browser may restrict clipboard access. Select the source or generated Python and copy it manually, or use the source download links for the stored run.

For a reproducible problem, send a small example with the displayed error and expected result. Contact information and reporting guidance explain what to include.
