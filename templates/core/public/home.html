04 / Know the boundaries

Useful results start with careful review.

plottwist targets a defined subset of MATLAB functionality for numerical and DSP scripts. Arbitrary MATLAB programs and every toolbox are not guaranteed to work.

Unsupported syntax may fail or need a different translation approach outside this workspace. Successful translation does not guarantee successful execution or correct numerical results.

Review generated Python, warnings, units, and plots whenever correctness matters.
