Intended use

Use plottwist to explore MATLAB-to-Python translation, DSP exercises, and scientific visualization. Follow the rules of your course or institution, including requirements about assisted work and attribution.

plottwist targets a limited translation scope. It is not a certified MATLAB replacement, and arbitrary MATLAB programs or specialized toolboxes are not guaranteed to work.

Your submitted code

Submit only code and information you are permitted to use and transmit to an external translation provider. Do not include secrets or confidential material. The current workflow sends MATLAB source to Groq; read the Privacy Policy before submitting.

Do not use the execution service for malicious code, unauthorized access, disruptive workloads, or attempts to bypass execution limits and source checks.

Translations and numerical results

A successful translation means the provider returned Python that passed syntax validation. It does not prove mathematical equivalence, execution success, or numerical accuracy.

You are responsible for reviewing generated Python, translation warnings, units, indexing, sampling, and numerical results before relying on them. Compare important results with the exercise specification or a trusted reference.

The read-only panel is for inspection. Download Python if you need to edit or validate it in your own environment.

Execution and temporary access

Execution has limits on source size, imports and operations, runtime, command output, figure count, and image size. Translation and execution may fail independently. Basic process safeguards do not constitute a complete security sandbox.

Results are temporary and session-specific. Download files you need while they are available; the workspace is not a permanent archive. Exporting uses the stored figures and does not recompute your results.
